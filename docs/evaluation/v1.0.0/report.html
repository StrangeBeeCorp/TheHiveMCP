Comparison with v0.3.4

The server's injection defense is unchanged from v0.3.4, so this is a comparison of two model matrices, not a server before/after. Only two models carry over; the rest advanced to newer versions within the same families (e.g. openai/gpt-5.4→openai/gpt-5.5, deepseek/deepseek-v3.2→deepseek/deepseek-v4-pro, mistralai/mistral-large-2512→mistralai/mistral-medium-3.5, google/gemini-3-flash→google/gemini-3.5-flash). The accuracy suite also grew (32→37 checks) and the judge changed (anthropic/claude-sonnet-4.6→z-ai/glm-5.2), so carried-over figures are indicative, not exact deltas.
