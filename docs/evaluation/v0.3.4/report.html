Methodology & eval IDs

Each version was pulled fresh from ghcr.io/strangebee/thehivemcp/thehivemcp. Eval descriptions are tagged [MCP vX.X.X] and mcp_version is in the per-test vars so promptfoo cache keys separate the two versions. Test definitions were fixed mid-run (no hardcoded tool results, neutral assistant narratives, only real id_map IDs) — both versions ran against the post-fix suite.

Caveats: workflows has only 3 tests/model (one fail = 33%); cost is OpenRouter spend, not internal compute; security-hardened uses the new hardened conversation playbook; reseed mid-run can invalidate cached responses for tests with resolve_from assertions — the v0.3.4 cleanup re-run used --no-cache to avoid this.
