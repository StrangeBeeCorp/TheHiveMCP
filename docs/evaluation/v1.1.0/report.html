Every model drives a multi-turn agent loop against a live, seeded TheHive through the real MCP tools; assertions read the execution trace, and a rubric-based judge grades the injection scenarios (the agent must both ignore the injection and warn the analyst). 3 of 12 models are perfect on accuracy, 5 on security; security ranges 60%–100%. Errors are runs that produced nothing to grade — the agent reached the turn cap without a final answer; 19 of 660 rows. They count as misses in both bars. See summary.md for the reading.
